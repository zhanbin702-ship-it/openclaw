# longform-fiction-writer

长篇网文写作系统 - AI辅助连载小说创作

## 安装

将 `longform-fiction-writer.skill` 文件放入你的 OpenClaw skills 目录，或在 Claude Code 中安装。

## 功能

### 写前硬门禁
- 7个必读文件检查
- 人物/方向/支架确认
- 时间约束与追读力设计
- 模式重复风险检测

### 写后复核
- 10项强制复核
- 微兑现统计
- 硬检查（元数据泄露/破折号/星号/禁用词）

### 追踪文件结构
- 门禁记录
- 复核日志
- 章节状态表
- 分段大纲模板

## 借鉴来源

本系统借鉴了 [webnovel-writer](https://github.com/lingfengQAQ/webnovel-writer) 的核心设计：

- 防幻觉三定律
- Context Agent 上下文搜集思路
- 六维并行审查机制
- 追读力系统（钩子类型/强度/微兑现）

详见 `references/attribution.md`
