# 长篇网文写作系统

一套完整的AI辅助长篇网文写作流程，解决"遗忘"和"幻觉"问题，支持长周期连载创作。

## 核心理念

### 防幻觉三定律（借鉴自 webnovel-writer）

| 定律 | 说明 | 执行方式 |
|------|------|---------|
| **大纲即法律** | 遵循大纲，不擅自发挥 | 写前强制加载章节大纲 |
| **设定即物理** | 遵守设定，不自相矛盾 | 一致性检查器实时校验 |
| **发明需识别** | 新实体必须入库管理 | 实体追踪与消歧 |

### 写作流程总览

```
写前门禁 → 写作执行 → 写后复核 → 硬检查 → 追踪文件更新
```

---

## 一、写前硬门禁

**任何章节正文前，必须先完成门禁。未完成不得动笔。**

### 1.1 必读文件清单

```
1. tracking/rewrite-north-star.md   ← 北极星，防跑偏
2. outline/series-bible.md          ← 圣经，锁核心承诺
3. tracking/dialogue-conflict-rules.md ← 对白与冲突规则
4. tracking/writer-review-log.md    ← 历史复盘记录
5. tracking/prewrite-gate.md        ← 门禁模板
6. tracking/external-checklist-adapter.md ← 补充检查层
7. chapters/CHAPTER-FILE-HEADER-TEMPLATE.md ← 章节头模板
```

### 1.2 门禁必填项

见 [references/prewrite-gate-template.md](references/prewrite-gate-template.md)

## 二、写作执行

### 2.1 核心结构模式

每章必须包含：

```
下套 → 收网 → 反扑 → 再收网
```

### 2.2 台词四要素

每段核心对话必须完成以下至少一项：

1. 推进剧情
2. 揭示人物
3. 制造冲突
4. 传递高价值信息
5. 制造悬念

### 2.3 权力语法（古风适用）

- 主语隐匿：不说"我"，用动作暗示
- 谓语悬置：不说"是"，用状态暗示
- 宾语共鸣：不说"你"，用关系暗示

---

## 三、写后复核

**交付前必须通过的复核项：**

| 序号 | 复核项 | 说明 |
|------|--------|------|
| 1 | 圣经主题框架复核 | 是否符合核心承诺与主线母题 |
| 2 | 结构复核 | 冲突链/证据链/爽点递增/章末钩子 |
| 3 | 去AI化复核 | 机器腔排查 + 人话口语审校 |
| 4 | 命名复核 | 标题只保留最关键爆点事件 |
| 5 | 对白与冲突复核 | 台词四要素/下套收网循环/古风去现代化 |
| 6 | 元数据泄露复核 | 正文不出现章节编号（C0XX） |
| 7 | 连贯性与场景复核 | 场景切换自然/时间线连贯/空间方位清晰 |
| 8 | 人物行为复核 | 符合人设/动机合理/无突然偏移 |
| 9 | 追读力复核 | 钩子强度/上章钩子回应/微兑现达标 |
| 10 | 模式重复复核 | 钩子类型/开头模式不连续3章同型 |

见 [references/review-checklist.md](references/review-checklist.md)

---

## 四、写后硬检查

**交付前必须通过，任一项不通过不得交付：**

| 检查项 | 规则 |
|--------|------|
| 元数据泄露 | 正文与对白不出现章节编号（如C0XX） |
| 破折号 | 古风正文不使用破折号 `——` / `—` |
| 星号 | 正文不出现星号 `*` 或 markdown 强调 |
| 禁用词 | 按项目规定（如古风不出现"程序"一词） |

## 六、追读力设计（借鉴 webnovel-writer）

### 6.1 钩子类型

| 类型 | 标识 | 驱动力 |
|------|------|--------|
| 危机钩 | Crisis Hook | 危险逼近，读者担心 |
| 悬念钩 | Mystery Hook | 信息缺口，读者好奇 |
| 情绪钩 | Emotion Hook | 强情绪触发（愤怒/心疼/心动） |
| 选择钩 | Choice Hook | 两难抉择，读者想知道选择 |
| 渴望钩 | Desire Hook | 好事将至，读者期待 |

### 6.2 钩子强度

| 强度 | 适用场景 |
|------|---------|
| **strong** | 卷末/关键转折/大冲突前 |
| **medium** | 普通剧情章 |
| **weak** | 过渡章/铺垫章 |

### 6.3 微兑现类型

| 类型 | 识别信号 |
|------|---------|
| 信息兑现 | 揭示新信息/线索/真相 |
| 关系兑现 | 关系推进/确认/变化 |
| 能力兑现 | 能力提升/新技能展示 |
| 资源兑现 | 获得物品/资源/财富 |
| 认可兑现 | 获得认可/面子/地位 |
| 情绪兑现 | 情绪释放/共鸣 |
| 线索兑现 | 伏笔回收/推进 |

## 八、快速开始

### 创建新章节

1. 创建 `tracking/prewrite-gate-C0XX.md`，填写门禁模板
2. 读完全部必读文件
3. 填写门禁必填项
4. 创建章节文件，贴入章节头模板
5. 按门禁规划写作
6. 完成后做硬检查
7. 更新 `tracking/chapter-status.csv`
8. 更新 `tracking/writer-review-log.md`

### 规划分段大纲

1. 确定本卷核心任务
2. 按段落拆分（如每段10章）
3. 每段明确功能、核心事件、章末钩子
4. 逐章细化目标/动作/回报/钩子
