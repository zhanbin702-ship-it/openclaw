# 写后复核清单

**交付前必须通过的复核项，每章必填，不得省略。**

---

## 强制复核项

### 1. 圣经主题框架复核
- 是否符合 `outline/series-bible.md` 的核心承诺与主线母题？
- 结论：`通过 / 不通过`

### 2. 结构复核
- 冲突链是否成立？
- 证据链是否成立？
- 爽点是否递增？
- 章末钩子是否成立？
- 结论：`通过 / 不通过`

### 3. 去AI化复核
- 是否通过机器腔排查？
- 是否通过人话口语审校？
- 结论：`通过 / 不通过`

### 4. 命名复核
- 标题是否仅保留当前章节最关键爆点事件？
- 结论：`通过 / 不通过`

### 5. 对白与冲突专项复核
- 是否通过台词四要素检查？
- 是否通过下套收网循环检查？
- 是否通过古风去现代化检查（若适用）？
- 结论：`通过 / 不通过`

### 6. 元数据泄露复核
- 正文与对白中是否出现章节编号（如 `C0XX`）？
- 结论：`通过 / 不通过`

### 7. 连贯性与场景复核
- 场景切换是否自然？
- 时间线是否连贯？
- 空间方位是否清晰？
- 情绪转折是否有铺垫？
- 结论：`通过 / 不通过`

### 8. 人物行为复核
- 人物行为是否符合人设？
- 动机是否合理？
- 是否有突然的性格偏移？
- 结论：`通过 / 不通过`

### 9. 追读力复核
- 钩子强度是否与章节类型匹配？
- 上章钩子是否在本章有回应？
- 是否存在可感知的未闭合问题/期待锚点？
- 微兑现是否达标（普通章≥1，过渡章可降级但需承诺下章补偿）？
- 结论：`通过 / 不通过`

### 10. 模式重复复核
- 钩子类型是否连续3章同型？
- 开头模式是否连续3章同型？
- 爽点模式是否连续5章同型？
- 结论：`通过 / 不通过`
