## F. 抓力与连贯补充检查

- 本章前 20% 的抓力来源是什么（即时冲突 / 异常信号 / 倒计时 / 结果先压脸 / 代价前置）？

- 本章明确接住了上一章哪个钩子、哪件证物、哪道口风或哪层关系变化？
- 本章是否新增了至少一项：新动作 / 新证 / 新后果？
- 本章核心对话是否都至少完成：推进剧情 / 揭示人物 / 制造冲突 / 传递高价值信息 / 制造悬念 之一？

## G. 时间约束板块

- 上章时间锚点：

- 本章允许推进跨度：
- 时间过渡要求：
- 倒计时状态（若有）：

**时间约束硬规则**：
- 若"与上章时间差"为跨夜/跨日，必须补写时间过渡
- 时间锚点不得回跳（除非明确标注为闪回章节）
- 若存在倒计时事件，推进必须正确（D-N 只能变为 D-(N-1)，不可跳跃）

## H. 追读力设计板块

### 钩子强度预期
- 本章类型：`普通剧情章 / 过渡铺垫章 / 关键转折章 / 卷末高潮章`
- 预期钩子强度：`weak / medium / strong`
- 钩子类型选择：`危机钩 / 悬念钩 / 情绪钩 / 选择钩 / 渴望钩`

### 微兑现计划
- 本章计划兑现的类型（可多选）：`信息兑现 / 关系兑现 / 能力兑现 / 资源兑现 / 认可兑现 / 情绪兑现 / 线索兑现`
- 预期微兑现数量：`≥ 1`（过渡章可降级为 0，但需在下章补偿）

### 模式重复风险检测
- 最近3章钩子类型：
- 本章钩子是否与上章同型：`是 / 否`
- 若连续3章同型钩子，必须更换类型

## I. 写后硬检查（交付前必须通过）

- 正文与对白中是否出现章节编号（如 `C0XX`）？
- 正文与对白中是否出现破折号 `——` / `—`？（古风正文不使用）
- 正文与对白中是否出现星号 `*` 或 markdown 强调符号？
- 正文与对白中是否出现禁用词？（按项目规定）
